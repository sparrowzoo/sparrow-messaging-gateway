# HTTP 与 WebSocket 来源 IP 统一实施计划

> 执行方式：主代理在本会话实施；用户已批准具体文件范围和单一配置。不提交、不推送，不修改部署环境。

**Goal:** 两个入口使用同一解析器、同一可信代理配置。

**Architecture:** 公共类放在 sparrow-shell/sparrow 的 com.sparrow.utility。HTTP、Netty 只提取输入；公共类不依赖 Servlet、Spring 或 Netty。

**Tech Stack:** Java 21、现有 Maven/JUnit 5。

**Spec:** 会话中已确认的六项改动，以及用户“两个配置请统一”“执行吧”。

## 约束

- 唯一配置 sparrow.client-ip.trusted-proxies；删除旧配置，不回退。
- 保留 WebSocket 从右向左检查可信代理的规则、重复头顺序及错误回退。
- 保留 HTTP 空请求返回 localhost、空对端返回空字符串。
- IPv4/IPv6 仅解析字面地址，不查询域名；不增加依赖。
- 不改已有 DefaultSession、LoginUser 的用户改动。
